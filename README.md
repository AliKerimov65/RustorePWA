# RuStore iOS — PWA-каталог

Веб-каталог приложений в формате PWA: поиск, карточки приложений, инструкция установки на экран «Домой» через Safari.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com (имя, например, `rustore-pwa`), **не** добавляйте README при создании.
2. Выполните в папке проекта:

```bash
git remote add origin https://github.com/<ВАШ_ЛОГИН>/rustore-pwa.git
git push -u origin main
```

3. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch → Branch: main / root → Save**.
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<ВАШ_ЛОГИН>.github.io/rustore-pwa/`

## Установка на iPhone (Safari)

1. Откройте ссылку в Safari.
2. Нажмите «Поделиться» → «На экран "Домой"» → «Добавить».
3. Иконка каталога появится на домашнем экране и откроется в полноэкранном режиме.

## Структура

- `index.html` — весь каталог (HTML + CSS + JS в одном файле, без внешних зависимостей).
